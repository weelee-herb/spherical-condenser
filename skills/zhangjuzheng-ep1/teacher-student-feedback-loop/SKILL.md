# 师生沟通反馈回路（肯定→引导→反思→行动）

## I — 方法论骨架 (Interpretation)

一次完整的反馈回路有五个环节：学生展示成果（写大字给老师看）→ 老师先肯定（夸奖一番）→ 转折提出引导（"一转，说了另外一番话"）→ 学生自己理解并反思（认为有道理、深刻反思）→ 学生主动采取行动（次日自己提出取消书法课）。

两个顺序是硬约束：肯定在建议之前——先认可已有成果，对方才有安全听下去；行动由对方发起——老师不直接下令，而是让对方想明白后自己提出改变。这条回路的目标不是"把话说到"，而是"让对方拥有改变动作"。

一句话骨架：先肯定 → 转折引导 → 留时间反思 → 让对方自己提出行动，不提就不代劳下指令。

## A1 — 应用示例 (Application Example)

### 示例 1: 书法课反馈（原书转述案例，c03）

- **类型与来源**: 原书转述案例，L375-L415。
- **问题/输入**: 十岁万历书法进步快，写了两个大字很得意，主动拿给张老师看（L381-L385）。
- **方法论的使用**: 肯定（"夸奖了一番"，L386）→ 转折引导（"一转，说了另外一番话"，L387-L397）→ 学生反思（"认为很有道理……做出了深刻的反思"，L407-L408）→ 主动行动（次日主动要求取消书法课，L411-L412）。
- **结论**: 完整跑通五环节回路，行动项由学生自己提出。
- **结果**: 原书报告"第二天……就主动要求取消了书法课"（L411-L412）；但同一案例后文被主讲人归为"扼杀小万历在书法上的兴趣"（L611-L614）——回路"技术正确"不等于结论正确，见 B 段。

### 示例 2: 给下属季度报告提改进建议（合成演练，原书无此案例）

- **类型与来源**: 合成演练（按 f09 回路规则复算，非作者经历）。
- **问题/输入**: 下属季度报告数据扎实但结论不清晰，需要提改进又不打击积极性。
- **方法论的使用**: 肯定（"数据部分做得很细，三条结论都带数字"）→ 转折引导（"如果读者只有一分钟，最该看到哪句话？"）→ 留时间给对方反思（停住，等对方回应）→ 让对方自己提出行动项。
- **结论**: 反馈脚本 + 对方自主行动项（如"我下次把结论提到第一页"）。
- **结果**: 演练输出；若对方不提行动项，按规则不代劳下指令，记录"未提出"。

## E — 可执行步骤 (Execution)

**必需输入**: 对方的成果/行为描述、反馈目标（想引导什么改变）。缺失时先询问，不猜。

**交付物与完成标准**: 反馈脚本（肯定句 / 转折句 / 引导句）+ 对方回应记录 + 自主行动项清单（无行动项时明确写"无"）。

1. **接收成果并先肯定**
   - 完成标准: ≥1 句指向具体优点的肯定（不空夸、不虚指）。

2. **转折提出引导**
   - 完成标准: 用"不过/同时"等转折引出改进方向，句子指向行为不指向人格。

3. **留时间给对方反思**
   - 完成标准: 给对方 ≥1 次回应机会，并记录对方回应（认同/质疑/沉默）。
   - 判停条件: 对方明确拒绝沟通 → 停止，不重复施压。

4. **让对方自己提出改变动作**
   - 完成标准: 记录对方"我打算……"的自提行动项。
   - 判停条件: 对方不提行动项 → 不代劳下指令，返回步骤 3 或结束并记录"未提出"。

5. **输出**
   - 完成标准: 脚本三要素齐 + 回应记录 + 行动项清单。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 安全事故、纪律红线等必须立即下指令的场景——回路需要反思时间，等不起。
- 对方已明确拒绝沟通，或关系已破裂。
- 纯表扬或纯批评的单向场合——回路需要"肯定 + 引导"两个要素同时在场。

### 作者在书中警告的失败模式

- **回路正确，结论可能错误**（ce03）：本卡与 f08 同源，同一书法课案例在原文后文被归为"扼杀小万历在书法上的兴趣"（L611-L614）。"先肯定后引导"只是形式，它同样可以服务于压制真实兴趣——"主动取消书法课"可能是顺从而不是认同（L415-L416"理解力超人的水平"是主讲人单方评价）。
- **"对方自提改变"不等于长期有效**（ce01）：L709-L711 明说强势教育促使万历表现出强烈逆反。在权力不对等的关系里，回路跑得越顺，越要警惕顺从而非内化。

### 作者的盲点 / 时代局限（来自阶段 0 批判）

- 主讲人未验证"深刻反思"与"主动行动"的内化程度，把次日行动直接当证据。
- 教育归因 vs 皇权政治：回路发生在"权高镇主"（L648-L650）的极端权力差关系中，脱离权力结构谈"沟通有效"会高估话术的作用。

### 容易混淆的邻近方法论

- f08（兴趣—责任权衡话术）：说服脚本 vs 反馈回路。
- f01（教育要素四维诊断）：关系诊断 vs 单次反馈。
