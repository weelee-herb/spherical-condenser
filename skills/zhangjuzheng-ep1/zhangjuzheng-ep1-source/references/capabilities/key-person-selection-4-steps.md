# 教师（关键人）选拔四步流程

## R — 原文 (Reading)

> 这时候从小带大小万里的四里边大太监冯宝，就给李太后说：说我可以给你找一个天底下最好的老师。（L175-L179）
>
> 在让谁做皇帝老师这个关键的位置上，冯宝当然要考虑，首先考虑自己的政治盟友。（L210-L212）
>
> 从此以后她就把小万利的教育和小万利的江山都托付给了这位张老师。（L242-L243）

— 郦波《大明脊梁张居正·第 1 集》（百家讲坛），转写稿

## I — 方法论骨架 (Interpretation)

一个关键岗位（教师、顾问、核心成员）的任命，原文给出四步：先想清楚要解决什么需求（李太后担心小皇帝位置坐不稳、教育抓不好）；然后接受中间人推荐（冯保举荐张居正）；接着一定要与候选人面谈验证，不能隔空定人（李太后与张居正一番深入交谈）；最后才授权，且授权时要同步给出支持承诺（教育与江山全托付 + 绝对无条件支持）。

四步之外，原文额外揭示一道隐藏的检查项：推荐人在关键位置上会优先考虑自己的政治盟友（"宝与居正深相结"）。所以选人不能只审候选人能力，还要审推荐人的动机、以及推荐人与候选人之间的利益关系。

一句话骨架：需求 → 推荐 → 面谈 → 授权，每走一步都把"推荐人动机"挂在旁边审查。

## A1 — 应用示例 (Application Example)

### 示例 1: 冯保推荐张居正任帝师（原书转述案例，c01）

- **类型与来源**: 原书转述案例（主讲人据《明史》等记载转述），L165-L247。
- **问题/输入**: 隆庆六年（1572）隆庆帝死，十岁万历仓促登基；李太后担心两件事——小皇帝的位置坐不稳、教育抓不好（L170-L174）。
- **方法论的使用**: 识别需求 → 接受中间人推荐（冯保以"天底下最好的老师"举荐张居正，L175-L189）→ 面谈验证（请张居正来，二人深入交谈，L232-L233）→ 授权（教育与江山全托付，L242-L243）；主讲人随即披露推荐环节的隐藏筛选条件——冯保优先考虑政治盟友（L205-L212）。
- **结论**: 张居正成为万历首席教师；授权范围是"教育 + 江山"两件事。
- **结果**: 万历新政十年由此展开；但"政治盟友"这条推荐动机到底占多大权重，主讲人自承"自晚明以来也有很大的纷争"（L213-L217），本集未定论。

### 示例 2: 给初一学生选家教（合成演练，原书无此案例）

- **类型与来源**: 合成演练（按 f06 四步规则复算，非作者经历）。
- **问题/输入**: 初一学生数学掉队，朋友推荐一位"名校在读生家教"。
- **方法论的使用**: 需求=数学及格并重建信心；接受推荐，同时问清朋友与家教的关系（是否有中介费/人情交换）；安排一次试讲面谈；确认后授权并约定家长支持方式（接送、反馈渠道）。
- **结论**: 任命决定 + 授权范围 + 动机审查结论。
- **结果**: 演练输出；若推荐人与候选人利益关系查不清，按规则暂停任命。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 家长为孩子选老师、家教、教练，手里有中间人推荐。
2. 管理者为团队任命关键负责人，有人内推候选人。
3. 用户复盘一次"看走眼"的任命，想知道当时哪一步漏了。
4. 用户拿到一个推荐，拿不准该先问什么、查什么。
5. 需要把"口头定人"变成可复查的任命流程。
6. 无中间人推荐的公开候选人也触发：注明推荐环节不适用（跳过该步），面谈验证与授权步骤可借鉴执行；需求说不清或利益关系查不清时，先询问或输出"动机未明"暂停结论。

### 语言信号 (用户的话里出现这些就应激活)

- "朋友给我推荐了一个老师/家教/顾问/合伙人，靠谱吗"
- "这个岗位人选怎么定？有人内推了"
- "我要不要直接录用他推荐的人"
- "当初怎么就选了他"
- 英文: "should I hire the person my friend recommended?" / "how do I vet a referral?" / "key hire decision" / "check the referrer's motive"

### 与相邻能力的区分（定稿，阶段 3 关系网）

- 与 f01（contrasts-with）：任命前用本卡走流程，任命后用 f01 诊断关系健康度，看时点选一。
- 与 f10（composes-with）：本卡"面谈验证"一步可用 f10 多源评估采集证据；f10 只评人，不给任命结论。

## E — 可执行步骤 (Execution)

**必需输入**: 岗位/学生需求（一句话可陈述）、推荐信息（推荐人是谁、与候选人什么关系、推荐理由）、候选人可面谈的条件。缺失"需求描述"或"推荐人—候选人关系"时先询问，不能静默猜值。

**交付物与完成标准**: 任命决定 + 授权范围 + 动机审查项，三项缺一不可；流程类输出按步骤记录，不留空档。

1. **识别需求**
   - 完成标准: 写出一句话需求，并给出 ≥1 条可验证的候选人条件（能力/经验/适配点）。
   - 判停条件: 需求说不清时，先回到询问，不进入推荐环节。

2. **接受中间人推荐并记录推荐链条**
   - 完成标准: 记录推荐人、推荐人与候选人的关系、推荐理由三项。
   - 判停条件: 推荐人与候选人存在利益关系且查不清 → 暂停任命，输出"动机未明"结论。

3. **面谈验证**
   - 完成标准: 完成一次直接面谈/试讲，产出匹配结论 + 疑虑清单。

4. **授权并给支持承诺**
   - 完成标准: 授权范围、支持方式书面化；支持承诺不写成"无条件"（见 B 段李太后反面）。

5. **输出动机审查项**
   - 完成标准: 给出推荐人动机假设 + 利益关系审查结论（有/无/未明）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 已有候选人但无任命场景，只是想"客观评价一个人"——用 f10 多源评估。
- 人选已上任，问题出在关系上——用 f01 四要素诊断。
- 无中间人的公开招聘流程（本流程以"推荐"为锚，不覆盖完整招聘）。

### 作者在书中警告的失败模式

- 推荐动机混入利益结盟：原文明说冯保推荐张居正有"政治盟友"动机（L205-L212），且该说法的史料可靠性"自晚明以来也有很大的纷争"（L213-L217）。把"了解才华"与"利益结盟"当成同一种信任，是原文自曝的风险点。

### 作者的盲点 / 时代局限（来自阶段 0 批判）

- 主讲人对"四最"的赞美带文学化滤镜：把"绝对无条件支持"当作"最好的家长"（L245-L247），但一次性把教育与江山全托付、不留复核机制，后来李太后态度 180 度翻转（L552-L556）——授权环节不设复核点，正是本流程的反面教材。
- 归因倾向：主讲人把任命成功主要归功于人选与信任，对"权臣与皇权的结构性矛盾"着墨在后。

### 容易混淆的邻近方法论

- f10（历史人物多源评估）：评人不走流程；本卡走流程不评人。
- f01（教育要素四维诊断）：任命前 vs 任命后。
