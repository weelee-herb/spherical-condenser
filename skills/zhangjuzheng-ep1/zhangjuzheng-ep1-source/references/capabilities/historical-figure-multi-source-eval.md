## I — 方法论骨架 (Interpretation)

评估一个人物，不采单一来源，而是把四类关系位置不同的评价并排开看：

1. 后世权威学者的总评——梁启超称他是"大明历史上唯一的一个政治家"。
2. 本朝正史的中性定位——《明史》称他"救时宰相"。
3. 生前政敌的评价——李贽是张居正"生前的一个大对头"，却赞他"宰相之杰"。
4. 后世学者的定位——黄仁宇称他是"智慧的象征"。

核心动作是主动去采反对者阵营的评价：连对立面都承认的优点，可信度高于任何单一来源的称赞。评估结论是"共识点与争议点"的结构，不是唯一定论。

注意："交叉印证"这一步是提取者从原文的并列罗列结构重建的，原书只并列四源、未明说"交叉"规则（见 B）。

### 示例 1：张居正的定级（原书案例，主讲人转述）

- **结果**: 原书未交代各评语的直接出处与原文页码；李贽评语的完整上下文亦未给。

### 示例 2：评估长期合作候选人（合成演练）

- **类型与来源**: 原书未提供现代案例，以下为合成演练。
- **问题/输入**: 候选人 A 有行业专家推荐信、现同事好评、一位前竞争对手的公开评价、离职员工的匿名评价。
- **方法论的使用**: 把四类来源映射为四格——权威专家、现同事（本朝同僚）、前竞争对手（生前政敌）、离职员工（后世复盘者）；重点核前竞争对手的评价。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想客观评价一个历史人物，怕被单一传记或单一说法带偏。
2. 招聘或合作前评估候选人，想听到反对声音，而不是只看推荐信。
3. 写人物稿、做人物选题，需要多角度定级与"共识/争议"结构。
4. 评估一个产品、方案或对手，想知道其对立面怎么评价。

### 语言信号 (用户的话里出现这些就应激活)

- "客观评价一下 XXX 这个人"、"他是不是被高估/低估了"、"有没有反对的声音"、"别只听一面之词"、"把不同说法摆在一起看"
- English: "give a balanced assessment of", "what did his opponents say", "evaluate this candidate objectively", "multi-source evaluation"

## E — 可执行步骤 (Execution)

**必需输入**: 被评对象（人名/产品/方案）+ 各来源评价材料，每条标注评价者身份、与对象的关系、评语（原话或转述）。缺失某类来源时先问"能否补齐"，不能静默跳过。

**交付物与完成标准**: 四源评价卡（来源身份/关系/评语/立场）+ 共识点—争议点对照 + 可信度结论。转述引文必须标注"转述，出处页码未核"。

1. **列出四类关系人来源**：权威专家、本朝同僚（当事人时代共事者）、生前政敌（对手阵营）、后世学者（复盘者）。
   - 完成标准: 四格各有 0–N 条评价，每条写明谁、什么关系、说什么。
2. **逐源采集，重点追问对手阵营**。
   - 完成标准: 至少尝试采集对手阵营评价；采不到如实留白并说明原因。
   - 判停条件: 若四类来源均无任何直接材料，停止并输出"材料不足，无法交叉印证"，不臆造评语。
3. **交叉印证**：找多源共同承认的点与各源独有的点。
   - 完成标准: 输出"共识点/争议点"两栏，每条标注来源。
4. **给可信度结论**：对手也承认的优点判"扎实"；仅单源的说法判"待核"。
   - 完成标准: 结论含各源立场 + 共识点 + 单源待核清单；不输出"唯一权威定论"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯史料考辨（哪句话出自哪卷哪页）: 本卡只做立场交叉，不做文献学核验。
- 只有单一来源材料: 交叉印证无从谈起，直接说明无法执行，不硬凑四源。
- 用户要求"给一个权威定论": 本卡输出的是共识/争议结构，不是唯一答案。

### 作者在书中警告的失败模式

- 主讲人示范了反模式本身：四源全部是正面评价，一条反对声音都没采——按本卡规则，应同时展示有损评价（"生前的大对头"若真说过坏话）。本集引文出处页码均未标注，把转述评语当史实引用会以讹传讹。

### 作者的盲点 / 时代局限

- 阶段 0 批判：主讲人只取"明朝亡于万历清算"一派说法，未呈现对立阵营完整论证——这正是本卡要防的单源偏差。
- 原名"三角评估法"与四类来源不符，slug 按实际语义定为多源评估。
- "交叉印证"逻辑系提取者从罗列结构重建，非原文直述；使用时把它当作提取约定，不要宣称是原书规则。
