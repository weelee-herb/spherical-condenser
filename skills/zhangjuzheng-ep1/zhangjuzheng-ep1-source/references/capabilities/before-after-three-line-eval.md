# 前后对比＋三线数据评估法

## R — 原文 (Reading)

> 第一，万利新政之前，国家财政每年巨亏将近300万两白银；但是万利新政执行两年之后，张居正的万利新政开始了两年之后，国库每年盈余就将近达到300万两。（L436-L440）
> 到万利八年张居正清查天下耕田数，是701万3976请。（L456-L457，"请"为 ASR 残留，即"顷"）
> 先用戚继光、俞大猷……平定了南方的倭寇。（L475-L477）

— 郦波，《大明脊梁张居正·第 1 集》新政成绩段（财政 L436-L448、土地 L449-L463、国防 L464-L498；引文逐字，标点为重组）

## I — 方法论骨架 (Interpretation)

- 评估一场改革的成效，用"干预前基线 vs 干预后同口径值"的结构。
- 至少选两条相互独立的指标线（原书用财政、土地、国防三线）交叉验证。
- 每条线必须同口径、同单位、带时点；口径不一致就停下来，不猜值。
- 只有一条指标线是孤证，不下结论。
- 给结果归因时，并列竞争性解释并明确表态（原书对壬辰战胜原因即如此处理）。

## A1 — 应用示例 (Application Example)

### 示例 1：万历新政三线评估（原书案例 c05/c06）

- **类型与来源**: 原书转述案例（财政 L436-L448、土地 L449-L463、国防 L464-L498）。
- **问题/输入**: "张居正给大明王朝带来了怎样的变化？"（L430-L432）。
- **方法论的使用**: 财政线——前: 每年巨亏近 300 万两（L436-L437）；后: 新政两年后年盈余近 300 万两（L438-L440）、1582 年中央存银 1250 万两（L443-L445）。土地线——前: 兼并严重、民不聊生（L449-L451）；后: 万历八年清丈 701 万 3976 顷，比弘治十五年多出近 300 万顷（L454-L459）。国防线——前: 四线危机、危如累卵（L464-L471）；后: 戚继光、俞大猷平倭，殷正茂平西南，反间计瓦解俺答（L473-L483）。
- **交叉验证**: 三线独立且方向一致。
- **结论**: "明王朝的实力迅速犹若转强"（L502）。
- **结果/限定**: 数据出处页码未给，属转述，需外部核对；归因须并列竞争解释——壬辰战胜原因有"丰臣秀吉病逝"与"张居正改革家底"两说，主讲人表态取后者（L490-L498）。

### 示例 2：线上课程改版复盘（合成演练）

- **类型与来源**: 原书未提供；以下为阶段 1.5 V2 走查的合成演练。
- **问题/输入**: 一次线上课程改版数据（改版前/后完课率、改版前/后用户评分）。
- **方法论的使用**: 定基线（前）→ 量干预后同口径值（后）→ 两条独立指标线交叉验证。
- **结论**: 前后对比表＋交叉验证结论。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估一次改版、改革、项目干预是否真的有效。
2. 用多指标交叉验证，防止单指标孤证。
3. 写复盘报告，需要统一的前后对比表格。
4. 检验别人宣称的"效果"是否可信（前后口径是否一致）。
5. 只有单指标（如仅完课率）或口径不明仍触发：按判停输出"单指标孤证，不足以下结论"，或先询问统一口径——不猜值、不静默不回应。

### 语言信号

- "效果怎么样""改版前后对比""改革成效""数据复盘"
- "before-after comparison" / "baseline" / "cross-validation" / "evaluate the impact"

### 与相邻能力的区分（定稿，阶段 3 关系网）

- 与 f10（contrasts-with）：交叉验证的两条路线——本卡用指标线评干预效果，f10 用关系人评人物/方案；评人用 f10，评干预用本卡。
- 与 p14（composes-with）：三线评估涉年号时借 p14 换算，统一时间口径。
- 与 f02（contrasts-with，登记于 f02 卡）：本卡用指标数字验证效果，f02 查要素间抵消机制。

## E — 可执行步骤 (Execution)

**输入契约**：必需——每条指标线的干预前值、干预后值、时点、单位与口径；至少两条独立指标线。口径/单位不明 → 停止并询问，不猜值；只有一条线 → 输出"孤证"而不下结论。

1. **定基线**：每条线记录干预前值＋时点＋口径。
   - 完成标准: 全部线有基线。
2. **量后值**：同口径、同单位取干预后值。
   - 完成标准: 全部线有后值。
   - 判停条件: 口径/单位不一致 → 停止，统一口径后再算。
3. **算变化**：Δ＝后−前（或比率，按指标性质），判定改善/恶化/持平。
   - 完成标准: 每条线有方向结论。
4. **交叉验证**：至少两条独立线方向一致才下结论。
   - 完成标准: 写明一致线数与不一致线。
   - 判停条件: 只有一条线或无一致 → 输出"单指标孤证，不足以下结论"。
5. **（补充步骤，源自 c06，L490-L498）竞争性解释并列与表态**：列出同一结果的其他解释，明确表态并给理由。
   - 完成标准: 记录 ≥1 条竞争解释，或写明"未发现竞争解释"。

**输出契约**：前后对比表（指标线/前值/后值/时点/口径/方向）＋交叉验证结论＋归因限定（数据无出处页码时标注"史料转述，需外部核对"）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只有"后"没有"前"（无基线）——不适用。
- 单指标且无法交叉——不下结论。
- 评估对象是人或团队特质——用 f10 或 f01。
- 教育关系健康度诊断——用 f01/f02。

### 作者在书中警告的失败模式

- 单线孤证: 原书敢下"由弱转强"结论靠的是三线；少于两线不下结论。
- 口径混淆（g07）: "300 万两"既是前亏额又是后盈额；"701 万 3976 顷"与"多出近 300 万顷"时点不同，不得混用。
- 归因过度（c06）: 把壬辰战胜单一归因张居正家底，主讲人表态但未证明——对应 E 步骤 5 必须列竞争解释。
- 数据出处页码未给（task-03 缺口，见 needs-review p08）: 本集数据均为转述。

### 作者的盲点 / 时代局限（阶段 0 批判）

- "明代 GDP 总量世界第一""尾巴上的 76 年靠张居正一人之力"是主讲人观点，无考证支撑，不得作为评估结论复用。
- 主讲人为叙事效果使用数据，未呈现对立阵营的完整论证。

### 容易混淆的邻近方法论

- f02（机制 vs 指标）、f10（评价来源 vs 指标线）、p14（纪年工具）。
