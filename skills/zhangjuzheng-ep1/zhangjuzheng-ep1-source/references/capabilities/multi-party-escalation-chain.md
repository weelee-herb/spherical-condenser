## I — 方法论骨架 (Interpretation)

一次小过失在多个监管主体之间被层层放大：学生喝酒闹事 → 陪读打小报告 → 老师上书批评 → 家长扬言废立 → 学生哀求 → 被迫向全天下公布检查书。五个环节每经过一个主体，惩戒级别就抬高一级，最终筹码（废帝位）远大于过失本身（青春期饮酒打架）。

这个链条的结构特征不是"惩罚重"，而是"多主体互相加码"：每个主体都在前一个主体的怒气上再推一把，谁都不负责回收压力。诊断方法就是画出"谁在放大谁的压力"的链条，检查三件事：有没有多主体互相加码、最重的筹码是不是用在了普通过失上、惩罚是不是面向第三方公开执行。三件里中一件，监管/惩戒体系就有过载风险。

一句话骨架：还原过失 → 画升级链 → 查三个过载信号 → 判定，细节不足就停在"无法判定"。

## A1 — 应用示例 (Application Example)

### 示例 1: 醉己诏（罪己诏）事件（原书转述案例，c10）

- **类型与来源**: 原书转述案例（主讲人据《明神宗实录》转述），L652-L687。
- **问题/输入**: 万历十八岁饮酒大醉、闹事打人——主讲人特意标注"这不过就是青春期的，一种躁动而已"（L658-L663）。
- **方法论的使用**: 画升级链：过失（醉酒打人）→ 冯保打小报告（L667）→ 张居正奋然上书批评（L668-L672）→ 李太后扬言废立、改立潞王（L675-L679）→ 万历万般哀求才松口（L680-L681）→ 逼写罪己诏，且向全天下公布（L682-L687）。三个过载信号全中：三主体互相加码、最重筹码（废帝位）用于普通过失、惩罚公开执行。
- **结论**: 升级链图 + 体系过载风险判定（过载）。
- **结果**: 原书报告了即时后果——"在这件事之后，说是小万历就开始消极怠功了"（L688-L690），且情感支柱转向郑贵妃（L691-L694）。这是"强势教育 → 逆反"因果链的起点。

### 示例 2: 实习生迟到被逐级上报至辞退威胁（合成演练，原书无此案例）

- **类型与来源**: 合成演练（按 f07 检查项复算，非作者经历）。
- **问题/输入**: 某公司实习生第一次迟到 20 分钟，直属主管在群内通报，部门负责人向 HR 报备，HR 口头提出"再犯就终止实习"。
- **方法论的使用**: 画升级链：迟到 → 群内公开通报 → 上报 HR → 辞退威胁。查信号：多主体加码（是）、最重筹码用于普通过失（是）、公开执行（是）。
- **结论**: 体系过载风险（判定为过载）；可撤的加码点：群内公开通报、HR 介入。
- **结果**: 演练输出；若各环节细节缺失，按规则停在"无法判定"，不默认过载。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 复盘一次"小过失被处理成大事"的事件：孩子小错挨重罚、员工小错被公开处分。
2. 设计家庭、班级、团队的惩戒规则，检查现有规则是否层层加码。
3. 多人共管一个孩子/项目，想理清"到底是谁在放大问题"。
4. 用户问"这件事罚得是不是太重了""要不要继续上报"。

### 语言信号 (用户的话里出现这些就应激活)

- "孩子犯了点小错，被搞得天翻地覆"
- "这件事要不要升级处理 / 上报领导"
- "惩罚是不是过度了"
- "他犯了点小错，怎么最后闹到要辞退/断绝关系"
- 英文: "was the punishment too harsh?" / "escalation chain" / "discipline overload" / "who amplified this?"

## E — 可执行步骤 (Execution)

**必需输入**: 过失事实（行为、时间、情境）、各方的反应与筹码（谁、对谁、做了什么、用了什么级别的手段）。缺失环节细节时先询问，不能脑补链条。

**交付物与完成标准**: 升级链图 + 三个过载信号逐项判定（是/否/无法判定）+ 总判定（过载 / 未过载 / 无法判定）+ 可撤销的加码点清单。

1. **还原过失事实**
   - 完成标准: 过失行为一句话说清，列出涉及的全部主体。

2. **画出升级链**
   - 完成标准: 链上每个环节都有"主体、动作、筹码、级别"四要素，环节按时间排序。
   - 判停条件: 链条环节缺细节且无法补问 → 跳步骤 4 输出"无法判定"。

3. **逐项检查三个过载信号**
   - ① ≥2 个主体互相加码；② 最重筹码（废立/辞退/断绝关系）用于普通过失；③ 惩罚面向第三方公开执行。
   - 完成标准: 三个信号各给出"是/否/无法判定"并附证据。

4. **判定**
   - 完成标准: ≥1 个信号为"是"且有证据 → "过载风险"；细节不足 → "无法判定"（不默认过载）。

5. **输出**
   - 完成标准: 升级链图 + 判定 + 按环节列出可撤的加码点（哪一步可收回、由谁收回）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只有单一管教者、不存在多主体链条的单人管教。
- 对历史事件做道德审判或"该不该罚"的定性——本卡只识别链条结构与过载，不判对错。
- 用于论证"重罚有效"：本卡的功能是识别过载，反向使用即为误用。

### 作者在书中警告的失败模式（含「强势教育 → 逆反」边界）

- **升级链的"成功"是假象**（ce04 + ce02）：万历哀求、写检查，当场看似被压制住了，但原文紧接着交代"在这件事之后……开始消极怠功"（L688-L690）。把"当场服软"当成"管教成功"，是本链最大的误用——恐惧换来的顺从不是成效。
- **最重筹码用于普通过失**（ce04）：原文自曝"这不过就是青春期的，一种躁动而已"（L658-L663），却上升到废帝位相胁、向全天下公布检查书——惩罚级别与过失失配。
- **强势教育 → 逆反的原文定论**（ce01）：L709-L711 明说"张居正的强势教育，促使小万历长大之后，表现出强烈的逆反来"。一次升级看似平息，长期积累逆反；本卡识别链条的目的正是防止这条因果链再次跑完。

### 作者的盲点 / 时代局限（来自阶段 0 批判）

- 主讲人把教育归因放在皇权政治之前：升级链走到"废立"一级时，已经进入皇权与权臣的结构性矛盾，教育诊断覆盖不了权力问题。用"教育"解释王朝兴衰属于过度归因。
- 李太后"气得要废掉小万历"是真心还是威慑，原文未辨析（L675-L679）——链条中最重一级的意图不明，判定时只能按"威胁级筹码"记录，不能脑补动机。

### 容易混淆的邻近方法论

- f01（教育要素四维诊断）：整体关系诊断，本卡是其中的惩戒子线。
- f02（「四最之和等于零」系统失效模型）：系统抵消 vs 链条放大。
- f08（兴趣—责任权衡话术）：说服话术，不涉及惩戒。
