# 按年龄适配教学材料的制作法

## R — 原文 (Reading)

> 考虑到小万里只是一个十岁的小孩，接受能力有限，所以张老师在偶心力炫的编教材的时候，就在教材的旁边、教学内容的旁边，画上画、连环画，以使得内容更加形象生动。（L307-L311）
> 小万里当时的表现就是喜动眼色，当时说翻得很勤快，很喜欢这本书。（L320-L322）

— 郦波，《大明脊梁张居正·第 1 集》《帝鉴图说》段（source/transcript-proofread.txt；引文逐字，标点为重组；"偶心力炫"为 ASR 残留，即"呕心沥血"）

## I — 方法论骨架 (Interpretation)

- 给低龄或理解门槛高的受众做教学材料，按三步走：评估接受能力 → 降低抽象度 → 观察使用反馈。
- 评估先行：年龄、已有知识、注意力决定材料的抽象层级；能力信息缺失就先采集，不猜。
- 降抽象的常用载体是配画、故事化、类比——形式可以简陋，适配优先于精美。
- 效果看可观察的使用行为（如翻看频率），而不是问一句"听懂了吗"。

## A1 — 应用示例 (Application Example)

### 示例 1：《帝鉴图说》连环画教材（原书案例 c02）

- **类型与来源**: 原书转述案例（L299-L330）。
- **问题/输入**: 给十岁小万历上"古代皇帝治国策略"这门专业基础课（L305-L306）。
- **方法论的使用**: ①评估——"考虑到小万里只是一个十岁的小孩，接受能力有限"（L307-L308）；②降抽象——在教材旁画连环画使内容形象生动（L309-L311）；③反馈——"喜动眼色""翻得很勤快""很喜欢这本书"（L320-L322）。
- **结论**: 学生喜欢教材；教材流传至今（L323-L326）。
- **结果**: 原书只报告"喜欢"，未报告学习效果；张居正"画也不咋地"（L317），复述不得拔高画技。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 给孩子、老人、外行讲明白一个抽象概念。
2. 设计或改版课件、绘本、图解、入门教程。
3. 判断现成教材是否适配特定受众。
4. 检验材料是否真被接受（观察使用行为，而非只听口头反馈）。
5. 问"孩子爱翻绘本/很喜欢是否等于学会"仍触发：给有效性限定——"喜欢"≠"学会"，原文只报告喜欢、未报告学习效果，不宣称学会。

## E — 可执行步骤 (Execution)

**输入契约**：必需——受众信息（年龄/已有知识/注意力/语言能力）、待讲概念、使用场景。受众能力信息缺失 → 先采集再设计，不猜值。

1. **评估接受能力**：写受众画像。
   - 完成标准: 画像含年龄、知识基线、注意力特征。
2. **降低抽象度**：概念 → 故事/画面/类比，产出方案与样例片段。
   - 完成标准: 样例的抽象层级 ≤ 受众画像层级。
3. **观察使用反馈**：定义可观察指标（如翻看频率）与观察方法。
   - 完成标准: ≥2 个指标及方法。
4. **迭代**：按反馈调整并记录；无法观察时输出"已设计，待实测"。
   - 完成标准: 记录调整项，不宣称有效。

**输出契约**：适配方案（受众画像/载体/呈现/样例）＋反馈观察项清单＋有效性限定（"喜欢"≠"学会"）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 受众是熟练者/专家、无理解障碍——不需要降抽象。
- 只做口头答疑、不产出材料——不适用。
- 要求证明学习效果（成绩提升）——原文未提供，需另做效果评估。

### 作者在书中警告的失败模式

- 把"喜欢"当"学会": 原文只报告"喜动眼色、翻得勤快"，未报告学习效果。
- 材料适配替代不了互动侧: 教材再好，配合强势压制仍可能逆反（ce01/ce02）。
- 形式简陋 ≠ 无效: 张居正不是美术老师、画也不咋地，材料仍被喜欢——适配优先于精美。

### 作者的盲点 / 时代局限（阶段 0 批判）

- "再也找不出一个为学生画插图本教材的语文老师"（L341-L343）是主讲人的修辞排他，非史料结论。
- "接受能力有限"是主讲人对十岁皇帝的转述判断；本集未证明该教材对学习效果（治国能力）的影响。
