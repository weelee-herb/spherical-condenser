# 教育要素四维诊断框架

## R — 原文 (Reading)

> 一个最好的老师，加一个最好的学生，加一个最好的家长，还有一个最好的陪族，四个一加在一起……（L16-L20）
> 还有当世最好的教学条件。（L12）

— 郦波，《大明脊梁张居正·第 1 集》开场段（source/transcript-proofread.txt；引文逐字，标点为重组；"陪族"为 ASR 残留，即"陪读"）

## I — 方法论骨架 (Interpretation)

- 把一段教育关系拆成四个角色格：老师、学生、家长、陪读（陪伴兼监督者），外加"教学条件"这一环境项（原书开场并列"最好的教学条件"但不计入"四最"口径）。
- 先逐格盘点：每一格给状态（最优/一般/短板/未知）并配证据，用观察代替印象。
- 判据沿用原书示例：老师看投入与教材适配、学生看悟性与尊师（不看成绩）、家长看支持方式、陪读看纪律与监督。
- 再查相互作用：谁支撑谁、谁压制谁、是否相互抵消——单格全优不等于系统成功。
- 最后给系统级结论：单项状态＋相互作用 → 健康度判断，并写明哪些结论有证据、哪些是推断。

## A1 — 应用示例 (Application Example)

### 示例 1：四"最"教育关系的系统诊断（原书案例）

- **类型与来源**: 原书转述案例，全片（关键段落 L16-L20、L243-L250、L285-L290、L305-L322、L586-L607）。
- **问题/输入**: 主讲人开场设问："这一切最好的因素，加在一起的结果又是什么"（L13-L14）。
- **方法论的使用**: 逐格填表——老师：每年提前亲自筹划教学大纲、提前几年编好计划、提前半个时辰到课堂（L285-L290）；学生：只称张居正"先生"、尊师且悟性"超人的水平"（L364-L372、L415-L416）；家长：对老师"绝对无条件支持"＋课后亲自检查功课（L244-L247、L594-L596）；陪读：课堂喊"皇上要听先生的话"维持纪律，一堂课喊七八遍（L586-L592）；环境：当世最好的教学条件（L12）。
- **结论**: 四格各有"最好"证据，主讲人给出的系统级结论却是"四个一加在一起……等于零"、最失败的教育（L20-L27）。
- **结果**: 1582 年毁灭力爆发，学生亲手毁掉改革成果（L527-L540）。

### 示例 2：现代教育关系诊断（合成演练）

- **类型与来源**: 原书未提供；以下为阶段 1.5 V2 走查的合成演练。
- **问题/输入**: 一段现代教育关系材料（学生、任课老师、家长、家教陪练各一人，附行为与结果描述）。
- **方法论的使用**: 逐格填四要素状态与证据 → 检查要素之间的相互作用 → 给系统级健康度结论。
- **结论**: 四要素状态表＋系统级结论（单项最优 ≠ 系统成功）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 家长或老师觉得"每个环节都挺好，孩子结果却不好"，想做一次教育关系体检。
2. 复盘一段师生/家校关系为什么出问题，需要先定位是单要素短板还是要素间抵消。
3. 给孩子选学校/家教/课外班组合、比较两套方案时，做系统级评估而非单项比较——方案比较也走四格盘点＋相互作用。
4. 把框架迁移到团队协作：明星成员＋好领导＋好资源，整体却失效。
5. 信息不全（某角色无行为证据、结果未交代）仍触发：按框架逐格盘点，缺证据格标"未知"并列入待采集清单；系统结论暂缓时输出"暂缓＋缺什么证据"，不回填不猜值。

### 语言信号

- "孩子教育哪里出了问题""老师学生家长都很好为什么还是不行""两套方案/组合怎么选""给我诊断一下这段教育关系"
- "education diagnosis" / "four factors of education" / "why is my child's education failing" / "teacher-parent relationship audit"

- 与 f02「四=零」（composes-with）：本卡步骤 3-4 即执行 f02 得系统级结论；f02 反向 depends-on 本卡（先逐格体检，再查抵消机制）。

- 与 f09 师生反馈回路（contrasts-with）：单次反馈不替代结构层诊断。

## E — 可执行步骤 (Execution)

**输入契约**：必需——角色清单（老师/学生/家长/陪读或其映射角色）、每角色的行为与证据、结果描述（是否出问题、出什么问题）。某角色行为证据缺失时标"未知"并列入待采集清单，不猜值；结果未交代时先询问。

1. **逐格盘点**四要素＋教学条件环境项，每格填"状态＋证据"。
   - 完成标准: 每格有状态与至少一条证据，或明确标"未知"。
2. **按判据判定每格**：老师看投入与教材适配、学生看悟性与尊师、家长看支持方式（是否绝对让渡）、陪读看纪律与监督。
   - 完成标准: 每格判定附观察来源。
3. **查相互作用**：列出要素间关系（支撑/压制/抵消），至少一条。
   - 完成标准: 有 ≥1 条关系描述；确无证据则明写"材料未显示相互作用"。
4. **系统级结论**：单项状态＋相互作用 → 健康度判断，标明证据充分处与不确定处。
   - 判停条件: 证据不足则输出"系统结论暂缓＋缺什么证据"，不回填。

**输出契约**：四要素状态表（要素/状态/证据/判定）＋相互作用清单＋系统级结论（含不确定性标注）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只问"这位老师/这个学生好不好"的单项评价——用单要素材料或 f06/f10，不上四维框架。
- 量化评估一项干预的效果——用 f03。
- 具体一次惩戒或沟通事件的定性——用 f07/f08/f09。

### 作者在书中警告的失败模式

- ce08: 只看单项、想靠换更强要素解决问题、总和不升反降——本集已证明全优可归零。
- ce01/ce02: 把恐惧顺从当成效（"立马老实""耸然惊起"），纪律依赖在场者而非内化规则。
- ce06: 家长"绝对无条件支持"（p03 正述）被 1582 反转证伪——"无条件"缺监督与边界。
- ce05: 权高震主而不自知——权力失衡是不在四要素内的隐藏变量。

### 作者的盲点 / 时代局限（阶段 0 批判）

- 主讲人把教育归因置于皇权政治之前；"四=零"是叙事框架，不是被证明的因果模型。
- 最强反对意见: 1582 清算实为皇权与权臣矛盾总爆发，任何权倾朝野的托孤首辅都难逃清算；用教育解释王朝兴衰把复杂因果压成了故事。诊断结论必须给政治/制度因素留位，不得独断归因教育。
- "四最"的赞美带文学化滤镜；李太后"无条件支持"、冯保"尽责"本身值得商榷。
