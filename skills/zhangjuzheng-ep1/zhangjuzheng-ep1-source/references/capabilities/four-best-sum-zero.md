# 「四最之和等于零」系统失效模型

## R — 原文 (Reading)

> 四个一加在一起，它并不等于四，甚至不等于三，不等于二，不等于一，它最后的结果竟然是等于零。（L20-L25）

— 郦波，《大明脊梁张居正·第 1 集》开场段（source/transcript-proofread.txt；引文逐字，标点为重组）

## I — 方法论骨架 (Interpretation)

- 当系统里每个要素单独看都是"最优"，整体却失败时，问题不在要素本身，而在要素之间的相互作用。
- 诊断顺序: 先确认各要素单项是否优秀 → 列出要素间相互作用 → 找使总和低于单项的抵消机制假设 → 给系统级失败结论。
- 停止追问"哪个要素不够好"，改问"要素之间在抵消什么"。
- 本模型只输出抵消机制假设，不提供普适机制清单——原文没有给，假设必须待验证。

## A1 — 应用示例 (Application Example)

### 示例 1：四最组合在 1582 年的系统失效（原书案例）

- **类型与来源**: 原书转述案例（L527-L559 现象级证据；四要素单项证据见 f01 卡）。
- **问题/输入**: 最理想的四最组合，在张居正死后"突然爆发出惊人的毁灭力来"（L527-L531）。
- **方法论的使用**: ①确认单项——四格各有"最好"叙事证据（L285-L290 等，见 f01 卡）；②列相互作用——家长绝对无条件支持 → 老师强势无制衡（L244-L247）；陪读课堂监督＋打小报告 → 惩戒升级（L586-L596、L666-L667）；③抵消机制假设——强势教育 → 长期逆反（L709-L711）；支持人格化绑定 → 家长态度 180 度反转（L552-L556）。
- **结论**: 系统级失败——创造力变毁灭力，改革成果被"吞噬殆尽"（L531-L535）。
- **结果**: 原书报告学生亲手毁灭成果、清算张家（L536-L545）；抵消机制的完整解释留待后续集（L709-L711 只给结论）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 复盘"全明星阵容却失败"的项目、团队、组织。
2. 解释"每个环节都对、整体却失败"的困惑（1＋1＜2）。
3. 教育或组织失败归因时，避免停在"哪个要素不够好"。
4. 事前风险检查：组建"梦之队"前先查抵消风险。

### 语言信号

- "每个环节都好为什么还是失败""全明星为什么输""1+1 为什么小于 2"
- "system failure" / "counteraction" / "why do great teams fail" / "the whole is less than the sum of its parts"

### 与相邻能力的区分（定稿，阶段 3 关系网）

- 与 f01（depends-on）：先逐格体检确认单项是否优秀，再查抵消机制；存在明显短板时转 f01（本卡 E 步骤 2）。
- 与 f03（contrasts-with）：同一失败问法的两条证据路线——本卡列抵消机制假设，f03 用前后指标验证效果。
- 与 f11（contrasts-with）：f11 特化"事业＋传人"双目标互相摧毁，本卡适用于任意多要素系统。

## E — 可执行步骤 (Execution)

**输入契约**：必需——各要素及其"优秀"证据、失败结果描述。失败结果或要素证据缺失时先询问；证据不足的要素标"未证实"。

1. **确认单项**：逐项列证据，判定"优秀/一般/短板"。
   - 完成标准: 每项有判定＋证据。
2. **判停**：若存在明显短板项 → 转 f01 逐格诊断；若全优仍失败 → 继续。
3. **列相互作用**：成对/成组写要素间影响。
   - 完成标准: ≥1 条关系描述；确无相互作用证据则输出"本模型不适用"。
4. **找抵消机制假设**：每条写成"A 作用于 B → 抵消/反转 C"的假设句。
   - 完成标准: ≥1 条假设并标注"待验证"；只输出假设，不宣称证实。
5. **系统结论**：单项 → 相互作用 → 机制假设 → 结论＋待验证项。
   - 完成标准: 明确"哪些已证实、哪些是假设"。

**输出契约**：单项判定表＋相互作用清单＋抵消机制假设清单（假设句＋证据线索）＋系统级失败结论（含不确定性标注）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 存在明显单项短板——用 f01 逐格诊断。
- 量化效果变化——用 f03。
- 不涉及"要素间相互作用"的简单归因问题。

### 作者在书中警告的失败模式

- ce08 预警信号: 只看单项、企图靠更换更强要素解决、总和不升反降。
- ce01: 强势教育短期有效、长期逆反——抵消机制有滞后性，短期成功不排除长期抵消。
- ce06/ce07: 支持人格化绑定导致整体翻转；把学生当自己事业的延伸，两件事最终成"矛盾体"（L703-L708）。
- ce05: 权高震主而不自知——权力失衡是四要素之外的隐藏变量。

### 作者的盲点 / 时代局限（阶段 0 批判）

- "四=零"是主讲人的叙事框架；要素间抵消机制的完整解释原文留待后续集，本卡只输出假设。
- 最强反对意见: 清算实为皇权与权臣矛盾的总爆发，与教育方式无关也可成立——不得把"四=零"当作已被证明的因果模型。
