# 决策规则速查 — 大明脊梁张居正·第 1 集（百家讲坛）

| 能力 | 一句话规则 |
|---|---|
| 教育要素四维诊断框架 | 先逐格评估老师、学生、家长、陪读四要素的状态与证据，再看要素之间如何相互作用，最后给系统级结论——单项最优不等于系统成功。 |
| 「四最之和等于零」系统失效模型 | 失败复盘时停止追问"哪个要素不够好"，改问"要素之间在抵消什么"——先确认各要素单项是否优秀，再列相互作用、找抵消机制假设，输出系统级失败结论。 |
| 前后对比＋三线数据评估法 | 定基线（干预前）→ 量干预后同口径值 → 至少两条独立指标线交叉验证；口径不一致时停止而不猜值。 |
| 按年龄适配教学材料的制作法 | 评估受众接受能力 → 降低抽象度（配图或故事化）→ 观察使用反馈；素材缺受众能力信息时先采集再设计，不猜值。 |
| 悬念钩子＋延迟揭晓的讲史叙事法 | 抛出反差设问 → 部分解答 → 保留核心谜底并声明"下期分析" → 下期开头兑现；前三步有原文示范，第 4 步兑现方式本集无示范。 |
| 教师（关键人）选拔四步流程 | 识别需求 → 接受中间人推荐 → 面谈验证 → 授权并给支持承诺；附加审查推荐人动机与双方利益关系，关系不明时暂停任命。 |
| 多主体层层加码的惩教升级链 | 画出"谁在放大谁的压力"升级链 → 检查是否多主体互相加码、最重筹码是否用于普通过失；无升级细节时停止于"无法判定"。 |
| 兴趣—责任优先级权衡话术（前车之鉴法） | 先给合法空间（爱好本身没错）→ 指向程度问题 → 说明排挤了什么 → 配一个可类比的失败先例；无合适先例时不硬套名人案例。 |
| 师生沟通反馈回路（肯定→引导→反思→行动） | 先肯定 → 转折提出引导 → 留时间让对方反思 → 让对方自己提出改变动作；对方不提行动项时不代劳下指令。 |
| 历史人物三角评估法 | 采四类关系人评价（权威专家、本朝同僚、生前政敌、后世学者）交叉印证，重点核对反对者阵营的评价；某类来源缺失时如实留白，不臆造评语。 |
| 双目标一体化设计框架（改革与接班人的矛盾体） | 并列"事业+传人"两目标 → 检查是否存在"传人反向摧毁事业"路径 → 输出风险预判；机制不完整处只标注风险，不虚构解释。 |
| 教学准备三项规则 | 三项核查——大纲是否提前亲自筹划、计划与内容是否提前编好、上课是否提前半个时辰（1 小时）到场；"提前几年"按课程周期等比调整。 |
| 年号纪年对照口径 | 万历 N 年 = 1572 + N；用原文两个锚点（隆庆六年=1572、万历十年=1582）回验，原文未给的年份不得自行倒推。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
